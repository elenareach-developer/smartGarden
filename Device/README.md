# Device — прошивки ESP32 для Smart Orchid

## Температура и влажность (DHT11) → приложение

Два способа доставить показания в приложение. Оба используют существующий API `POST /api/sensors/readings`.

| | Как работает | Когда выбрать |
|---|---|---|
| **A. Wi-Fi** `smart_orchid_dht11_wifi/` | ESP32 сам отправляет среднее раз в минуту | Основной вариант: ESP32 может стоять у растения на любом зарядном |
| **B. USB-мост** `serial_bridge/` | Компьютер читает монитор порта и пересылает данные | Сразу, с исходным скетчем `temp_humidity_working_copy`, без перепрошивки |

### Шаг 1. Запустить backend так, чтобы его видел ESP32 (для варианта A)

```bash
cd backend && source .venv/bin/activate
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

`--host 0.0.0.0` открывает сервер для локальной сети. Компьютер и ESP32 должны быть в одной Wi-Fi-сети (2,4 ГГц).
Если macOS или Windows спросит про входящие подключения для Python — разрешите.

### Шаг 2. Зарегистрировать датчик и переключить растение (один раз)

В приложении: **Settings → Зарегистрировать IoT-датчик**:
- **Растение:** например, Луна;
- **Тип:** DHT11;
- **hardware_id:** `esp32-orchid-dht11`.

Затем в разделе **Источник данных растений** переключите это растение на **IoT**.

### Шаг 3A. Wi-Fi-прошивка

1. Arduino IDE → Library Manager: установите **DHT sensor library** (Adafruit) и **Adafruit Unified Sensor**.
2. Скопируйте `smart_orchid_dht11_wifi/secrets.example.h` в `secrets.h` (та же папка) и заполните:
   - имя и пароль Wi-Fi;
   - `SERVER_URL` — IP компьютера, например `http://192.168.1.50:8000`. Узнать IP на macOS: `ipconfig getifaddr en0`;
   - `PLANT_ID`.
3. Откройте `smart_orchid_dht11_wifi.ino`, выберите плату ESP32 и загрузите.
4. В мониторе порта (9600) раз в минуту появится `✓ Отправлено в Smart Orchid`.

### Шаг 3B. USB-мост (без перепрошивки)

```bash
cd Device/serial_bridge && pip install -r requirements.txt
python serial_bridge.py --port /dev/cu.usbserial-0001 --plant-id 1
```

Порт на macOS — `ls /dev/cu.*`, на Windows — `COM3`. Закройте монитор порта Arduino IDE: порт может занимать только одна программа.

### Что увидите в приложении

**Monitoring** → у растения температура и влажность с меткой **IoT**, время измерения и график истории.
Остальные показатели (свет, субстрат) честно показывают «нет данных», потому что DHT11 их не измеряет.
Прогноз начнёт строиться после 3 полных суток измерений.

### Частые ошибки

| В мониторе порта | Причина |
|---|---|
| `HTTP -1` | Сервер недоступен: не тот IP, backend запущен без `--host 0.0.0.0` или брандмауэр |
| `HTTP 404` | Датчик не зарегистрирован, или `HARDWARE_ID` не совпадает с указанным в Settings |
| `HTTP 422` | Датчик привязан к другому растению (`PLANT_ID`), или значение вне допустимого диапазона |
| `Sensor reading failed!` | Проверьте провод DATA на пине 4 и питание датчика |

> DHT11 — бюджетный датчик: точность ±2 °C и ±5 % влажности. Для точного климата лучше SHT31.
